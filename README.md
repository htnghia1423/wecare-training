# Wecare Training — Power Apps Web Resources

Dự án chứa các **web resources** (JavaScript, HTML, CSS) tuỳ chỉnh cho **Power Apps Model-Driven App** của **Công ty Cổ phần Wecare Group**, phục vụ hệ thống quản lý bán hàng và kho hàng nội bộ.

## Tính năng

- **In Đơn Bán** — Phiếu in đơn hàng với đầy đủ thông tin khách hàng, sản phẩm và tổng tiền, mở ở tab mới trực tiếp từ form Đơn bán.
- **Validate Xuất kho** — Kiểm tra số lượng xuất không vượt quá tồn thực tế, hiển thị cảnh báo và tự động reset field khi vi phạm.

## Tech stack

- Power Apps Model-Driven App
- Microsoft Dataverse (Web API v9.2)
- JavaScript / HTML / CSS (web resources)
